# ASSET_PIPELINE.md

## Regra

Gerar somente assets que tragam ganho visual objetivo.

## Antes de gerar

Definir:

1. função narrativa;
2. motivo para não usar CSS;
3. proporção;
4. resolução;
5. perspectiva;
6. iluminação;
7. transparência;
8. formato;
9. destino;
10. mobile;
11. fallback.

## Preferência

- cena-base gerada;
- textos no DOM;
- terminal no DOM;
- cursor no DOM;
- luz e interação controladas pelo código.

## Segurança

Nunca inserir credenciais no front-end.
