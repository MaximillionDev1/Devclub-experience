# Codex Workflow

## Comando de alto nível

Exemplo:

```text
Use a skill $devclub-experience.
Execute OP-001.
```

## Fluxo obrigatório

1. Ler ordem de produção.
2. Ler arquivos citados.
3. Confirmar dependências.
4. Confirmar créditos disponíveis.
5. Preparar prompt versionado.
6. Apresentar especificação antes de gerar.
7. Gerar apenas uma versão inicial.
8. Registrar resultado.
9. Aplicar Quality Gate.
10. Aprovar, rejeitar ou pedir uma correção objetiva.
11. Otimizar.
12. Integrar.
13. Validar desktop/mobile.
14. Atualizar Asset Library e Current State.

## Proibições

- gerar múltiplas variações sem aprovação;
- gastar crédito por curiosidade;
- alterar direção criativa;
- integrar draft;
- sobrescrever approved;
- colocar assets brutos no bundle;
- expor credenciais.

## Relatório

- asset;
- ferramenta;
- prompt usado;
- custo/créditos, se disponível;
- saída;
- avaliação;
- decisão;
- próximos passos.
