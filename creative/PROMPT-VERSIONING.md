# Prompt Versioning

## Estrutura

```text
creative/production/prompts/
├── HERO-02/
│   ├── v01.md
│   ├── v02.md
│   └── final.md
└── HERO-01/
    ├── v01.md
    └── final.md
```

## Regras

- nunca sobrescrever;
- registrar alterações;
- uma mudança por versão;
- correções devem ser objetivas;
- manter prompt final idêntico ao usado na geração aprovada.

## Registro

Cada versão deve conter:

- data;
- ferramenta;
- objetivo;
- alteração;
- prompt;
- negative prompt;
- resultado;
- decisão.
