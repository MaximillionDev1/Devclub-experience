# Instalação

Copie a pasta `creative/` para a raiz do projeto.

Estrutura:

```text
projeto/
├── creative/
├── docs/
├── src/
├── AGENTS.md
└── package.json
```

## Logo

A logo de referência já está em:

```text
creative/references/devclub-logo.jpg
```

## AGENTS.md

Adicione à seção de fontes de verdade:

```md
Para produção visual, leia `creative/README.md` e a ordem de produção relacionada.
Nenhum asset pode ser gerado sem ordem de produção.
```
